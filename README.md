# Smart Subscription Guard (SubGuard)

An Enterprise Financial Operations Dashboard for Intelligent Subscription Management

Smart Subscription Guard (SubGuard) is a production-ready FinTech SaaS dashboard designed to help organizations monitor, analyze, and optimize their recurring software subscriptions. Built with a premium, corporate-light aesthetic, SubGuard helps finance teams eliminate ghost subscriptions, track underutilized licenses, and automate compliance auditing.

## Key Features

### 1. Enterprise Login Gateway

Secure, professional authentication interface for authorized financial administrators and corporate users. Smooth state transition post-login leading straight to the main analytics workspace.

### 2. Interactive Analytics Dashboard Layout

Global Overview: Real-time tracking of Total Money Saved, Monthly Spend, and active vs. underutilized software applications.
Smart User Context: Profile controls customized for executive actions like CFO / Admin view.

### 3. The 4-Step Subscription Guard Funnel

Step 1 — Analyze Usage: Real-time tracking of software utilization metrics like Slack Pro or HubSpot to instantly flag low-engagement accounts.
Step 2 — Renewal Check: Interactive financial grid syncing upcoming billing dates with credit cards like Visa or Mastercard to eliminate surprises.
Step 3 — Smart Alert: Proactive alert flags notifying administrators of immediate action required on low-usage apps.
Step 4 — Auto-Cancel: Fully interactive action panel that simulates secure, dynamic subscription purging and instant updates to the global Money Saved counter.

### 4. Fully Interactive Admin Modals

Dynamic overlay pop-ups for Profile Settings, Billing Configuration, API Key Generation, and Audit Logging. Clean state-driven open/close transitions aligned with contemporary UI patterns.

### 5. Regulatory and Compliance Framework

In-built enforcement layouts honoring global financial and security standards like SOC 2 Type II, GDPR, PCI-DSS, and CCPA.

## Tech Stack

Frontend: React.js (Vite)
Styling: Tailwind CSS (Modern corporate light theme)
Icons: Lucide React
State Management: React Hooks using useState and useEffect
Version Control: Git and GitHub

## Getting Started and Installation

Follow these quick steps to set up and run the project locally:

1. Clone the Repository
git clone [https://github.com/aroobanaveed/smart-subscription-guard.git](https://www.google.com/search?q=https://github.com/aroobanaveed/smart-subscription-guard.git)
cd smart-subscription-guard
2. Install Dependencies
npm install
3. Run the Development Server
npm run dev

Open http://localhost:5173 in your browser to view the live dashboard.
